# 🌿 Plant Disease Detection

This is a Machine Learning based web application that detects plant diseases from leaf images.

## 🚀 Features
- Upload leaf images
- Detect diseases like:
  - Blight
  - Healthy
  - Rust
- Fast prediction using trained model

## 🛠️ Technologies Used
- Python
- Scikit-learn
- Streamlit
- NumPy
- PIL

## 📂 Project Structure
- train.py → Model training
- app.py → Web app
- dataset/ → Training data
- model/ → Saved model

## ▶️ How to Run
```bash
pip install -r requirements.txt
streamlit run app.py
```
